# Rasphia WhatsApp Commerce Overview

Rasphia enables end-to-end commerce through WhatsApp, not just support chat or lead capture. A customer can discover products, choose a merchant, create an order, complete payment, receive invoice updates, check order status, and raise post-purchase requests without leaving the conversational flow. At the same time, merchants can manage catalog, stock, orders, and business insights from WhatsApp as well.

This document explains how Rasphia turns WhatsApp into a full commerce operating layer for both users and merchants.

## The Core Idea

Traditional brands use WhatsApp only for:

- answering questions
- sharing payment screenshots
- manually collecting addresses
- resolving support issues after the sale

Rasphia makes WhatsApp a true commerce channel where the platform handles:

- identity and role awareness
- merchant context
- product discovery
- order creation
- checkout handoff
- payment verification
- invoice generation
- post-purchase messaging
- refunds, replacements, and cancellations
- merchant operations and analytics

This means the conversation itself becomes the storefront, checkout assistant, and operations layer.

## End-to-End Commerce for Users on WhatsApp

### 1. User onboarding and identity

Rasphia starts by identifying whether the person is a user or merchant and keeps session context across messages.

User-side capabilities:

- User registration through WhatsApp
- Persistent WhatsApp session context
- Role-aware guidance
- Verified profile linkage with user details
- Reuse of saved profile information across future conversations

This makes the flow feel continuous instead of restarting from zero every time a user comes back.

### 2. Product discovery through conversation

Users can discover products in natural language rather than browsing static category pages.

Discovery capabilities:

- Conversational product search
- AI-assisted product matching
- Merchant-specific shopping context
- Product image delivery directly in WhatsApp
- Product recommendations based on user intent
- Product exploration across merchants or within a chosen merchant

Instead of making the user translate intent into filters, Rasphia helps the user reach the right product through chat.

### 3. Merchant-specific shopping context

Users can switch into a specific merchant context and shop that merchant directly inside WhatsApp.

Capabilities:

- Merchant context selection in chat
- Merchant-aware product discovery
- Merchant-specific ordering flow
- Merchant-specific post-purchase interactions

This is especially useful for merchants who want customers to move from Instagram or WhatsApp directly into a structured purchase flow.

### 4. Order creation inside the WhatsApp flow

Once a user chooses a product, Rasphia can help create the order conversationally.

Order creation capabilities:

- Quantity-aware order creation
- Address collection in chat
- Saved address selection
- Verified user-profile-based customer data usage
- Merchant-grouped order creation logic
- Consistent internal order IDs for tracking

This avoids the common WhatsApp-commerce problem where merchants manually ask for name, phone, address, quantity, and payment proof in separate messages.

### 5. Checkout handoff from WhatsApp to Rasphia checkout

Rasphia keeps the conversational flow but uses a structured hosted checkout when needed for payment completion.

Checkout capabilities:

- Hosted Rasphia checkout links generated from WhatsApp
- Razorpay-first payment experience
- Preloaded customer details from verified profile data
- Address-aware checkout flow
- Quantity-aware checkout
- Consistent checkout experience between WhatsApp and website

This keeps payments structured and auditable while still starting from chat.

### 6. Payment verification and confirmation

After the user completes payment, Rasphia verifies the order and updates status.

Payment capabilities:

- Payment confirmation support from WhatsApp
- Verified order status updates
- Unified payment verification flow aligned with the web experience
- WhatsApp confirmation replies after payment success
- Clear final order status messaging

This is much better than asking users to send screenshots and waiting for manual confirmation.

### 7. Internal invoice generation and delivery

After payment verification, Rasphia can handle invoicing within the same commerce flow.

Invoice capabilities:

- Internal invoice generation
- GST-aware invoice structure
- PDF invoice generation
- Invoice storage
- Invoice email delivery
- WhatsApp messaging about invoice success or failure
- Invoice link sharing when available

This means the user does not just pay in WhatsApp. They also receive proper order completion and invoice follow-up in the same journey.

### 8. Order tracking and order queries on WhatsApp

Users can come back later and query their orders directly in WhatsApp.

Order query capabilities:

- Latest order lookup
- Paginated order querying
- Query by verified customer details
- Internal order ID based lookup
- Status visibility for paid, processing, shipped, and delivered orders
- Merchant-scoped order visibility when shopping within a specific merchant context

This turns WhatsApp into a usable order hub rather than a one-time sales entry point.

### 9. Post-purchase support in the same chat

Rasphia keeps post-purchase actions inside the same thread so users do not need to move to a different support system.

Support capabilities:

- Refund requests
- Replacement requests
- Cancellation requests
- Eligibility checks based on order status
- Structured request capture
- Request timeline creation

This is a major upgrade over informal DM-based support because the requests are stored and tied to actual orders.

## End-to-End Commerce for Merchants on WhatsApp

### 1. Merchant onboarding in chat

Merchants can get started directly from WhatsApp without needing a separate admin onboarding call just to begin setup.

Merchant onboarding capabilities:

- Merchant registration via WhatsApp
- Merchant profile capture
- Store context setup
- Role-based merchant mode

This reduces the friction for small and independent merchants who already live in WhatsApp.

### 2. Catalog creation and updates in chat

Merchants can manage products conversationally.

Catalog capabilities:

- Product creation through WhatsApp
- Product updates through WhatsApp
- Product image handling
- Product lookup and query support
- Bulk-minded operational simplicity for fast catalog changes

This is useful for merchants who do not want to log into a dashboard for every small catalog edit.

### 3. Inventory management in chat

Rasphia makes stock control accessible from WhatsApp.

Inventory capabilities:

- Stock query by product
- Stock update by product
- Zero-stock confirmation workflow for sensitive changes
- Availability synchronization with product state

This helps merchants keep catalog accuracy high even when operations are handled from mobile.

### 4. Active order operations

Merchants can monitor and act on live orders via WhatsApp.

Order operations capabilities:

- Active order lookup
- Order detail visibility
- Customer detail visibility for merchant-owned orders
- Order status updates
- Confirmation gates for sensitive actions

This lets merchants actually run commerce from chat, not just market from chat.

### 5. Merchant analytics through conversation

Rasphia lets merchants ask business questions in natural language over WhatsApp.

Analytics capabilities:

- Total sales today
- Total sales last month
- Best-selling items
- Items that need restocking
- Users with items active in cart
- Conversational summaries of operational performance

This turns WhatsApp into a lightweight command center for merchants.

### 6. Merchant visibility into service requests and fulfillment outcomes

Rasphia connects customer after-sales workflows back to merchant operations.

Capabilities:

- Visibility into refund, replacement, and cancellation requests
- Order-linked service request records
- Timeline-aware support context
- Better operational traceability than manual DM support

This helps merchants manage the full customer lifecycle from the same commerce channel.

## Why Rasphia’s WhatsApp Commerce Is Better Than Traditional Shopping

### 1. It removes channel fragmentation

Traditional flow:

- discovery happens on Instagram
- customer queries happen on WhatsApp
- checkout happens on a separate link
- payment proof is sent manually
- invoices happen somewhere else
- support happens in scattered messages

Rasphia flow:

- discovery starts in WhatsApp
- order context stays structured
- checkout is generated from the conversation
- payment verification feeds back into the same journey
- invoices and support remain tied to the same order

### 2. It reduces manual work for merchants

Traditional WhatsApp selling usually means:

- repeating the same questions
- manually collecting addresses
- manually confirming stock
- checking payments by hand
- sending invoices separately
- losing track of support issues

Rasphia automates and structures these steps so merchants can scale beyond informal chat selling.

### 3. It feels more natural for users

Many users are already comfortable buying through conversation, especially in categories driven by taste, trust, or merchant familiarity.

Rasphia improves that pattern by adding:

- structured order creation
- guided checkout
- verified payment completion
- proper invoice handling
- reliable order queries later

So the experience keeps the comfort of chat without the chaos of manual commerce.

### 4. It gives merchants operational power, not just messaging

Most conversational commerce tools stop at:

- lead capture
- canned replies
- support automation

Rasphia goes further and enables:

- product operations
- stock operations
- order operations
- service requests
- analytics queries

That is what makes it an end-to-end commerce system rather than a support bot.

### 5. It creates continuity across the full lifecycle

In traditional systems, pre-purchase, checkout, payment, and post-purchase often live in different tools.

In Rasphia’s WhatsApp commerce flow, the user can:

- discover
- buy
- pay
- verify
- receive invoice updates
- track orders
- request support

all within the same conversation layer.

## The Full End-to-End WhatsApp Commerce Loop

For users:

1. Start a WhatsApp conversation with Rasphia
2. Discover products or choose a merchant
3. Select product and quantity
4. Use saved details or provide delivery information
5. Open Rasphia checkout from WhatsApp
6. Complete Razorpay payment
7. Receive payment confirmation
8. Trigger invoice generation and email delivery
9. Query order status later in WhatsApp
10. Raise refund, replacement, or cancellation requests if needed

For merchants:

1. Register on Rasphia through WhatsApp
2. Add products and manage stock
3. Receive orders through the Rasphia commerce layer
4. Track active orders in WhatsApp
5. Update fulfillment status
6. Review business insights in chat
7. Handle service outcomes with better order context
